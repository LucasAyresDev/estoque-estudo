No dia de hoje eu aprendi:

  Node.js > 
- não é uma linguem.
- permite rodar javascript fora do navegador.
- é usado para criar servidores APIs e sistemas backend.
- ele vem com módulos nativos como http.

  Npm >
- vem junto com o node.
- é um gerenciador de pacotes do node. 
- com ele nós conseguimos adicionar dependências para o projeto.



  ESM & CJS >
- aprendi a diferença entre eles
- ESM é o novo sistema de módulo usado para projetos em node.js
- tive que mudar manualmente no package.json o "type" para :module pois o projeto foi criado em CJS (acho que isso acontece por padrão, mas talvez dê para mudar na hora da criação, ainda não descobri)


  HTTP >
- basicamente o servidor fica "escutando" nossos pedidos quando criamos a função server.listen 
- é o protocolo que o navegador e o servidor usam para se comunicarem.

  REQ & RES >
- requisitos e respostas.
- req é o que o navegador pediu, res é a resposta do servidor.
- res.statusCode 200 é a resposta que deu tudo certo
- res.setHeader aqui eu to dizendo para o navegador como ele vai interpretar o conteúdo que ele vai receber.
- res.end é a resposta enviada pelo servidor, sem isso o navegador ficaria esperando uma resposta para sempre.

  CONST >
- cria uma variável que nao pode mudar de valor.
- é usada para que evitemos erros nos códigos.
